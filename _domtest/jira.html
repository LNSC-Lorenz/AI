Jira 使用方法速查

Atlassian Jira（敏捷 / 看板 / 缺陷跟踪） · 快速上手
日期：2026-10-25

一、基本操作

  1. 登录：访问团队 Jira 地址（如 jira.example.com），用公司账号登录。
  2. 选择项目：顶部切换「项目」，进入对应的项目看板。
  3. 创建任务：点击右上角 Create → 选择 Issue Type（Story / Bug / Task）→ 填写 Summary、Description、Assignee、Sprint。
  4. 流转状态：拖动看板卡片或点击任务，按工作流（To Do → In Progress → Done）推进。

二、常用搜索（JQL）

  • 我的任务：assignee = currentUser() AND status != Done
  • 某迭代的 Bug：sprint = "Sprint 12" AND type = Bug
  • 最近 3 天创建：created < -3d
  • 优先级高：priority = High ORDER BY created DESC

三、常用快捷键

  • c 创建任务 · r 快速创建
  • / 打开命令面板 · ? 显示快捷键
  • a 分配给自己 · j 跳转

四、缺陷（Bug）处理流程

  1. 复现并记录：步骤、期望结果、实际结果、环境、截图。
  2. 指派并定级：Assignee + Priority（Blocker / Critical / Major / Minor）。
  3. 关联：使用 is related to / blocks / clones 关联 Story 或其它 Bug。
  4. 修复验证：开发改完 → QA 验证 → 状态改 Resolved / Closed。

五、任务字段说明

字段含义
Summary任务标题（一句话）
Description详细描述 / 验收标准
Assignee经办人
Reporter报告人
Sprint所属迭代
Priority优先级
Status当前状态
💡 提示：把常用过滤器 保存 (Save as) 为「我的待办 / 我的 Bug」，可一键回到工作区。
