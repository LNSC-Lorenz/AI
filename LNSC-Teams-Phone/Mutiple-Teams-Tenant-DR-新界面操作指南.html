Multiple Teams Tenant Direct Routing 配置指南
—— 基于当前新版界面的操作过程

依据原文件《Mutiple-Teams Tenant DR Setup guide - For-General - WQYL_ENDVERSION》整理  |  适用入口：Microsoft 365 管理中心（admin.microsoft.com）+ Teams 管理中心（admin.teams.microsoft.com）

一、原指南内容概要

原 PPT 为多租户 Teams 直接路由（Direct Routing）配置指南（运营商/服务商 SBC 场景，子域格式 XXX.alc.aisesz.com），共 7 步：

步骤原指南内容
1在 Office 365 中添加子域（TXT 验证，发电信添加 DNS 记录）
2创建活动用户（用子域后缀，分配 O365 + Phone System 许可证）
3创建拨号计划 Dial Plan（含中国号码规范化规则）
4创建 PSTN Usage / 语音路由策略（名称 customization）
5用 PowerShell 创建语音路由（Voice Route 指向运营商 SBC）
6给用户分配 DID 号码和策略（单个/批量）
7在 Teams 客户端验证拨号盘

原 PPT 截图基于旧版 Office 365 管理门户和旧版 Teams 管理中心。以下为当前新界面中的对应操作。

二、新界面操作过程

步骤 1：添加子域名

入口：Microsoft 365 管理中心 → 左侧"设置" → "域"

  1. 点击 "+ 添加域"，输入子域：XXX.alc.aisesz.com（XXX 为客户名）
  2. 验证方式选择 "添加 TXT 记录"（即原指南的 "Add your own DNS Records"）
  3. 复制 Microsoft 给出的 TXT 名称 / TXT 值 / TTL，发给中国电信，等待电信在 DNS 服务器添加完成
  4. 回到域页面点击 "验证"
  5. 后续"如何连接域"页面不要勾选任何服务（Exchange / SharePoint / Skype for Business），直接下一步 → 完成
  6. 用 ping XXX.alc.aisesz.com 验证解析，公网 IP 应为 129.227.85.2（未生效则需等待 DNS 传播）

步骤 2：创建活动用户

入口：Microsoft 365 管理中心 → 用户 → 活动用户 → "+ 添加用户"

  1. 用户名后缀选择刚添加的子域，如 TeamsVoice@xxx.alc.aisesz.com
  2. 分配许可证：Office 365（如 E3/E5）+ Teams Phone Standard（原"Phone System"许可证，E5 已内置）

步骤 3：创建拨号计划（Dial Plan）

入口：Teams 管理中心 → 语音(Voice) → 拨号计划(Dial plans) → "+ 添加"

  1. 输入名称和描述
  2. 在"规范化规则"下点击 "添加"，逐条创建规则（规则自上而下匹配，限制性强的放上面）：
名称模式 (Pattern)转换 (Translation)
LocalFixPhone^([2-8]\d{7})+86512$1（按城市区号，如上海 +8621$1）
LocalMobile^(1\d{10})$+86$1
LongdisMobile^(01\d{10})$+86$1
LongdisFixPhone^0((([12]0|2[2-9])\d{5,8}|21\d{5,10}|[3-9][1-9]\d{5,9}|(701|90[1-9])\d{5,7}|80[2678]\d{5}|95\d{3}))\d*(\D+\d+)?$+86$1
Tollfree^([48]00\d{7}|10800\d{7})\d*$+86$1
Service^(999|1\d{2}|1\d{4}|9\d{4})$+86$1
International^(?:\+|00)(1|7|2[07]|...)(?:0)?(\d{6,14})(\D+\d+)?$+$1$2
转分机^(\d{4})$（4位分机）如 +86512628888;ext=$1
  1. 可用页面上的 "测试拨号计划" 输入号码即时验证转换结果

步骤 4：创建语音路由策略（PSTN Usage）

入口：Teams 管理中心 → 语音(Voice) → 语音路由策略(Voice routing policies) → "+ 添加"

  1. 名称：customization
  2. 在"PSTN 使用记录"下点 "添加 PSTN 使用记录"；若不存在，点 "添加" 现场新建同名记录
  3. 点击"应用" → "保存"
✅ 新界面变化：旧版需在单独页面先建 PSTN Usage，现在建策略时可直接内联新建。

步骤 5：创建语音路由（Voice Route）

入口：Teams 管理中心 → 语音(Voice) → 直接路由(Direct Routing)

✅ 新界面重大变化：原指南此步必须用 PowerShell，现在可直接在界面完成，无需命令行。
⚠️ 多租户（运营商托管）场景的关键点：按微软现行官方模型（运营商主干中继 carrier trunk + 客户派生中继 derived trunk），客户租户不需要、也不应在 "SBC" 选项卡自行添加 SBC（即不要运行 New-CsOnlinePSTNGateway）。主干中继由运营商在其租户中创建；客户租户只需在语音路由中以"派生中继"方式引用 SBC FQDN。旧模型（客户租户自建 SBC 条目）已被官方建议尽快迁移到新模型。
  1. 切到 "语音路由(Voice routes)" 选项卡 → "+ 添加"（或选择已有语音路由后编辑）
  2. 填写：
    • 名称：customization
    • 号码模式：^\+
    • 优先级：1
  3. 在 "SBCs enrolled"（已注册的 SBC）下点 "添加 SBC" → 在右侧弹出面板选择 "以派生中继方式添加 SBC (Add SBC as derived trunk)"，输入本租户的派生中继 FQDN（即步骤 1 已验证的子域，如 XXX.alc.aisesz.com）→ 添加 → 应用
    （派生中继自动继承运营商主干中继的全部配置参数；若填写的派生中继无效，系统将拒绝保存）
  4. PSTN 使用记录：选择步骤 4 创建的记录

注：运营商侧需将派生中继 FQDN 的 DNS 记录解析到其 SBC 的 IP 地址（原指南中公网 IP 129.227.85.2）。

仍可用 PowerShell 方式（需 MicrosoftTeams 模块）：

Install-Module MicrosoftTeams
Connect-MicrosoftTeams
New-CsOnlineVoiceRoute "customization" -NumberPattern '^\+' `
  -OnlinePstnGatewayList XXX.alc.aisesz.com -Priority 1 `
  -OnlinePstnUsages "customization"

注：派生中继无需运行 New-CsOnlinePSTNGateway；若官方界面暂不可用，官方文档同样认可用 New-CsOnlineVoiceRoute 完成。

步骤 6：给用户分配 DID 号码和策略

入口：Teams 管理中心 → 用户 → 管理用户(Manage users) → 点击用户

单个用户：

  1. "帐户(Account)" 选项卡 → "常规信息" → 已分配的电话号码 → 编辑 → 号码类型选 Direct Routing，输入 E.164 格式 DID，如 +8651262888002 → 应用（此操作会自动为用户启用企业语音）
  2. "策略(Policies)" 选项卡 → 编辑 → 分配：语音路由策略 = customization、拨号计划 = 步骤 3 创建的计划

批量分配：

  • 在"管理用户"列表勾选多个用户 → 使用顶部的编辑设置 / 分配策略批量操作；或用 PowerShell：
Set-CsPhoneNumberAssignment -Identity user@xxx.alc.aisesz.com `
  -PhoneNumber "+8651262888002" -PhoneNumberType DirectRouting
Grant-CsOnlineVoiceRoutingPolicy -Identity user@... -PolicyName "customization"
Grant-CsTenantDialPlan -Identity user@... -PolicyName "你的拨号计划名"

注：自 Teams PowerShell 7.9.0（2026 年 7 月）起，Set-CsPhoneNumberAssignment 的主参数名改为 -TelephoneNumber / -NumberType，旧参数名 -PhoneNumber / -PhoneNumberType 保留为别名，向下兼容，原有脚本无需修改。

⚠️ 注意事项（沿用原指南）：
• 所有 Teams 语音用户必须有 Teams Phone（Phone System）许可证
• 共存模式必须为 Teams only；若是 Islands 模式需先向微软咨询迁移方案
• 旧命令 Set-CsUser -OnPremLineURI 已被 Set-CsPhoneNumberAssignment 取代

步骤 7：验证拨号盘

用户在 Teams 客户端打开"通话" → 应显示拨号盘和自己的 DID 号码。若不显示：注销重新登录，或等待一段时间让 Microsoft 后台同步生效。

四、新旧界面主要差异总结

  1. 域管理：旧 O365 门户 → 新 Microsoft 365 管理中心"设置 → 域"
  2. Phone System 许可证 → 现名 Teams Phone Standard
  3. PSTN Usage：旧版独立页面先建 → 新版可在语音路由策略内联创建
  4. 语音路由：旧版只能 PowerShell → 新版"语音 → 直接路由 → 语音路由"选项卡界面化配置
  5. DID 分配：旧版用户页"帐户 → 编辑" → 新版"管理用户 → 帐户 → 已分配的电话号码"，且命令行改用 Set-CsPhoneNumberAssignment
