Lead Sync Rule

MarketUP and Salesforce Lead Sync Rules

Every 30 minutes, the system checks both sides for leads that have changed recently. If only one side changed, it syncs the changed side; if both sides changed, Salesforce takes precedence.

Sync every 30 minutesIncremental fetch by update timeSalesforce wins on conflict
1

Lead Basic Information Sync

The sync direction is determined by the update time of the records on each side. If both sides were modified at the same time, Salesforce takes precedence.

01 · Incremental Query Scope

Fetch the leads to sync based on their update time

The system records the time of the previous query on each side, and each round fetches only the leads that were updated after that point in time.

Step 1
Record the last query time

MarketUP and Salesforce each store the time of their own previous query.

Step 2
Query recently updated records

Every 30 minutes, query only the leads that were updated after the last query time.

Step 3
Decide the sync direction

Once the changed leads are found, decide which side should overwrite the other.

Query scope: only leads updated after the previous query time are queried.
02 · Sync Decision Rules

Determine the sync direction from the update time on both sides

The sync decision is based on the update time of the lead record and does not consider which specific fields were changed.

MarketUP changedSalesforce changedHandling this round
NoNoNo action; wait for the next round.
YesNoMarketUP → Salesforce
NoYesSalesforce → MarketUP
YesYesSalesforce → MarketUP, Salesforce wins
Conflict rule: if both sides modified the same lead before this round's check, MarketUP accepts the entire set of basic information from Salesforce, so the changes MarketUP made this round may be overwritten.

04 · Sync Time Records

Time records after a completed sync

This lets the next round keep querying only changed records, and also makes it possible to tell which side a lead changed on.

Query time per system

MarketUP stores MarketUP's last query time; Salesforce stores Salesforce's last query time. The next round queries only the leads updated after each system's own time.

Salesforce update time per lead

After a successful sync, MarketUP stores the record update time returned by Salesforce. The time returned by the Salesforce server is authoritative, not the time the request was sent.

MarketUP update time per lead

It also stores the last confirmed update time of this lead in MarketUP, which is used in the next round to determine whether MarketUP has made new changes.

Records update only on success

If this round's sync fails, the previous time records are kept and processing continues in the next round, so a failure is never mistaken for a completed sync.

Time basis: MarketUP uses the record update time returned by Salesforce as the sync baseline, not the time the API request was sent.
2

Lead Follow-up Record Sync

We recommend maintaining follow-up records in MarketUP only, and syncing them to Salesforce after they are created or updated.

01 · Single Place to Maintain

Follow-up records should only be created and edited in MarketUP

To avoid maintaining the same follow-up record on both platforms, use MarketUP as the primary platform for entering follow-up records and Salesforce as the platform where the synced results are displayed.

MarketUP
Create or edit a follow-up

Sales reps record follow-up content such as phone calls, meetings, and WeChat conversations in MarketUP.

Sync processing
Detect new or changed records

The system creates sync jobs based on the update time of the follow-up record.

Salesforce
Sync the follow-up record

Create or update the corresponding follow-up activity in Salesforce.

02 · Create and Update Rules

Follow-up changes in MarketUP are synced to Salesforce

Action in MarketUPHandling in Salesforce
Create a follow-up recordCreate the corresponding follow-up activity in Salesforce
Edit an already synced follow-up recordUpdate the corresponding follow-up activity in Salesforce
View the sync result in SalesforceYou can view the synced follow-up content and time
Record mapping: each MarketUP follow-up record is linked to its corresponding activity in Salesforce. Editing updates the original record instead of creating a duplicate.
03 · Usage Rules

Maintain each follow-up record on only one platform

Recommended practice

Create or edit follow-up records in MarketUP, and the system syncs them to Salesforce automatically.

How Salesforce is used

View the synced results in Salesforce. Directly editing the same synced follow-up is not recommended.

Maintenance principle: if the follow-up content needs to be adjusted, always make the change back in MarketUP and let the system sync it to Salesforce, so that editing on both sides cannot cause inconsistencies.
