Salesforce Data Request

MarketUP and Salesforce Data Request Plan

MarketUP works with Salesforce through the standard Salesforce REST API to query, create and update contacts, and to create and update visit reports. The sections below list the sandbox configuration MarketUP needs from the Salesforce team, followed by the Java request examples used for joint testing.

01 · Configuration Requested

Please help configure the following in the sandbox

These four items cover the OAuth application, the integration user's permissions, the credentials MarketUP needs, and the object metadata required for the visit report.

1

OAuth application

Configure an OAuth application that supports the Client Credentials Flow, assign a dedicated integration user, and enable the API access scope (api).

2

Integration user permissions

Enable the API Enabled permission for the integration user, and authorize the data within the sync scope:

  • Contact: read, create and edit permissions.
  • The object that actually backs the visit report: read, create and edit permissions.
  • Related objects such as Account: read permission as required by the relationships.
  • Synced fields: read permission; write permission for fields that are editable.
3

Connection credentials

Provide the sandbox My Domain URL, the Client ID (Consumer Key) and the Client Secret (Consumer Secret).

4

Visit report object metadata

Provide the object and field API names, required fields, picklist values, record types and relationships for the visit report. If the visit report uses a main object plus a detail object, please provide both.

02 · Endpoints to Use

Salesforce REST API endpoints

All of the business paths below start with /services/data/{version}; use a {version} that the sandbox supports.

PurposeMethodPath
Get an access tokenPOST/services/oauth2/token, using the sandbox My Domain
Query contacts by update timeGET/services/data/{version}/query?q=...
Query contact details and update timeGET/services/data/{version}/sobjects/Contact/{Id}
Create a contactPOST/services/data/{version}/sobjects/Contact
Update a contactPATCH/services/data/{version}/sobjects/Contact/{Id}
Create a visit reportPOST/services/data/{version}/sobjects/{report object API name}
Update a visit reportPATCH/services/data/{version}/sobjects/{report object API name}/{Id}
Query object field definitionsGET/services/data/{version}/sobjects/{object API name}/describe
Version note: {version} is a placeholder - use the API version supported by the sandbox, for example v60.0.
03 · Spring Boot Request Example

Spring Boot (Java) request example

The sample below uses the JDK HTTP client and Jackson, so no extra Salesforce SDK is required.

application.yml
salesforce:
  domain: ${SF_DOMAIN}
  client-id: ${SF_CLIENT_ID}
  client-secret: ${SF_CLIENT_SECRET}
  # Example only; use the version supported by the sandbox
  api-version: v60.0
SalesforceClient.java
import com.fasterxml.jackson.databind.JsonNode;
import com.fasterxml.jackson.databind.ObjectMapper;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.stereotype.Service;

import java.io.IOException;
import java.net.URI;
import java.net.URLEncoder;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;
import java.nio.charset.StandardCharsets;
import java.time.Duration;
import java.time.Instant;
import java.util.Map;

@Service
public class SalesforceClient {

    @Value("${salesforce.domain}")
    private String domain;

    @Value("${salesforce.client-id}")
    private String clientId;

    @Value("${salesforce.client-secret}")
    private String clientSecret;

    @Value("${salesforce.api-version}")
    private String apiVersion;

    private final ObjectMapper mapper = new ObjectMapper();

    private final HttpClient http = HttpClient.newBuilder()
            .connectTimeout(Duration.ofSeconds(10))
            .build();

    // 1. Get a token with the Client ID and Client Secret
    public JsonNode getToken() throws IOException, InterruptedException {
        String form = "grant_type=client_credentials"
                + "&client_id=" + encode(clientId)
                + "&client_secret=" + encode(clientSecret);

        HttpRequest request = HttpRequest.newBuilder()
                .uri(URI.create(domain.replaceAll("/+$", "")
                        + "/services/oauth2/token"))
                .timeout(Duration.ofSeconds(30))
                .header("Content-Type", "application/x-www-form-urlencoded")
                .POST(HttpRequest.BodyPublishers.ofString(form))
                .build();

        return execute(request);
    }

    // 2. Query contacts by update time: returns the first page
    public JsonNode queryContacts(JsonNode token, Instant since)
            throws IOException, InterruptedException {

        String soql = "SELECT Id, FirstName, LastName, MobilePhone, "
                + "Email, AccountId, LastModifiedDate "
                + "FROM Contact "
                + "WHERE LastModifiedDate >= " + since.toString()
                + " ORDER BY LastModifiedDate, Id";

        return call(token, "GET", apiPath() + "/query?q=" + encode(soql), null);
    }

    // 3. Query a single contact: after a write, read the update time Salesforce actually stored
    public JsonNode getContact(JsonNode token, String contactId)
            throws IOException, InterruptedException {

        return call(token, "GET",
                apiPath() + "/sobjects/Contact/" + contactId, null);
    }

    // 4. Create a contact or visit report; on success returns JSON containing the id
    public JsonNode createRecord(
            JsonNode token, String objectApiName, Map<String, Object> fields)
            throws IOException, InterruptedException {

        return call(token, "POST",
                apiPath() + "/sobjects/" + objectApiName, fields);
    }

    // 5. Update a contact or visit report; a successful call usually returns HTTP 204
    public void updateRecord(
            JsonNode token, String objectApiName, String recordId,
            Map<String, Object> fields)
            throws IOException, InterruptedException {

        call(token, "PATCH",
                apiPath() + "/sobjects/" + objectApiName + "/" + recordId,
                fields);
    }

    private JsonNode call(
            JsonNode token, String method, String path, Object body)
            throws IOException, InterruptedException {

        // Business endpoints use the instance_url from the token response
        String baseUrl = token.get("instance_url").asText();
        String accessToken = token.get("access_token").asText();

        HttpRequest.BodyPublisher publisher = body == null
                ? HttpRequest.BodyPublishers.noBody()
                : HttpRequest.BodyPublishers.ofString(
                        mapper.writeValueAsString(body));

        HttpRequest request = HttpRequest.newBuilder()
                .uri(URI.create(baseUrl + path))
                .timeout(Duration.ofSeconds(30))
                .header("Authorization", "Bearer " + accessToken)
                .header("Content-Type", "application/json")
                .method(method, publisher)
                .build();

        return execute(request);
    }

    private JsonNode execute(HttpRequest request)
            throws IOException, InterruptedException {

        HttpResponse<String> response = http.send(
                request, HttpResponse.BodyHandlers.ofString());

        if (response.statusCode() < 200 || response.statusCode() >= 300) {
            // Do not log the secret, the token or contact data in the error message
            throw new IOException(
                    "Salesforce request failed, HTTP " + response.statusCode());
        }

        return response.body().isBlank()
                ? mapper.createObjectNode()
                : mapper.readTree(response.body());
    }

    private String apiPath() {
        return "/services/data/" + apiVersion;
    }

    private static String encode(String value) {
        return URLEncoder.encode(value, StandardCharsets.UTF_8);
    }
}
04 · Sample Calls

How the client is used

The calls below are made from a business method that has SalesforceClient sf injected. The sample update operations only touch sandbox test data.

SalesforceClient usage
// Get a token: reuse it for the whole round; there is no need to fetch one per request
JsonNode token = sf.getToken();

// Query the contacts updated after the given time
JsonNode contacts = sf.queryContacts(
        token, Instant.parse("2026-09-20T00:00:00Z"));
// Update a contact: replace this with the real ID of the sandbox test contact
String contactId = "replace-with-sandbox-ContactId";

sf.updateRecord(token, "Contact", contactId, Map.of(
        "LastName", "Zhang San",
        "MobilePhone", "13800000000"
));

// After a successful update, query the update time that the Salesforce server actually generated
JsonNode contact = sf.getContact(token, contactId);
String sfModifiedTime = contact.get("LastModifiedDate").asText();

// MarketUP stores sfModifiedTime as the baseline for the next sync decision on this contact
// Create a visit report
// The object and field names below are placeholders only and do not represent the customer's current Salesforce configuration
JsonNode report = sf.createRecord(token, "Visit_Report__c", Map.of(
        "Subject__c", "Customer visit",
        "Content__c", "Discussed product requirements and the follow-up plan",
        "Contact__c", contactId
));

// MarketUP stores the returned report ID and updates the same record on later edits
String reportId = report.get("id").asText();

sf.updateRecord(token, "Visit_Report__c", reportId, Map.of(
        "Content__c", "Added the customer's feedback; follow up again next week"
));
Note: the code above is a request example, not a complete sync program.
