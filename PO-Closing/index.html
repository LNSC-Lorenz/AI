关于 · PO-Closing 平台逻辑

  1. 发票进　ap-invoice 共享邮箱的发票统一转发到内网 Exchange 邮箱 auto@lechler.com.cn →「读取邮件」（手动，或每天 03:00 / 12:00 定时）→ 解析 XML 附件 → 按年写入 invoice/*.csv
  2. 载入　打开页面自动合并读取 invoice 文件夹全部 CSV（发票号 / PO号 / 供应商 / 金额 / 日期 / 编号 / 开票内容），去重展示
  3. 核查　「批量查询 SAP」按 PO 查净收货（收货 − 冲销退货，含容差），判定 完整收货 / 部分收货 / 未收货 / 查无此单；每天 03:33 / 12:33 自动核查（⚙ 设置里可改时间）
  4. 关闭　完整收货行（浅底+黑条）勾选 →「标记关闭选中 PO」→ 服务端 SQLite 留痕；真实写 SAP 关单（BAPI_PO_CHANGE）属第二阶段
  5. 留痕 / 导出　通知日志、核查结果、设置全部存本机 SQLite；「导出」把当前筛选结果生成 Excel
技术原则：除内网 Exchange / SAP 外零外部通信；前端纯展示，全部判定逻辑在服务端 · PO-Closing v1.0
